UNDER THE HOOD

A small engine.
Real information retrieval.

Folio runs the original C++ project as WebAssembly. The browser adds an interface; the existing classes do the searching.

  1. 01 · LoadRead the sample .txt files, or add your own to the current session.
  2. 02 · Tokenize & indexLowercase alphanumeric tokens map to document IDs and occurrence counts.
  3. 03 · Query & rankDeduplicate query terms, match any term, and sum term frequency × inverse document frequency.
  4. 04 · InspectRead the matching document and see each term’s contribution to its score.
score = Σ TF × [1 + ln((N + 1) / (df + 1))]

N = documents in the collection · df = documents containing a term

Equal scores use ascending document ID. Punctuation splits words; phrases, fuzzy matching, and Unicode tokenization are not supported. The terminal app and its snapshot storage are preserved in the source.
